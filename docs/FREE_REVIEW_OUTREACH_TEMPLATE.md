# Free / Pro-Bono Review Outreach Template

Use this template only to request legitimate review of the authorized staging scope. Do not send secrets, personal data, production credentials or confidential contracts.

## Security review request

Subject: Open-source mutual-aid platform — request for pro-bono staging security review

Hello,

I maintain an open-source mutual-aid community platform and I am preparing it for a controlled staging validation. I am looking for a qualified security reviewer who may be willing to provide a limited pro-bono/community review.

The review is strictly authorized against a designated staging environment with synthetic accounts/data. Production systems, real payment rails, social engineering, destructive testing and denial-of-service are out of scope.

The repository contains a prepared scope package, current automated security evidence and reproducible OWASP ZAP results. The goal is an independent review of authentication/authorization, WebAuthn/session controls, IDOR/BOLA, webhook replay/idempotency, payment-state integrity and PII boundaries.

If this is something your chapter/lab/community can evaluate, I can provide the public repository and the authorized staging scope. Credentials, if required, will be shared through a secure channel and never through Git.

Thank you.

## Rules for outreach

- contact organizations individually; do not mass-message or spam;
- tailor the request to the chapter/lab/clinic;
- use email/contact forms where appropriate rather than automated bulk messaging;
- never imply endorsement before a reviewer accepts the scope;
- record only non-sensitive review references in the repository.
