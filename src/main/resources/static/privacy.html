Política de Privacidade

O Fazer o Bem trata dados pessoais para cadastro, segurança, análise de pedidos, prevenção a fraude, atendimento de direitos do titular e prestação de contas compatível com a privacidade.

Dados tratados

Podem ser tratados dados cadastrais, dados de autenticação, CPF, endereço, documentos comprobatórios, histórico de solicitações e registros técnicos de segurança. Dados sensíveis devem ser limitados ao estritamente necessário ao caso.

Proteção

O projeto utiliza segregação de acesso, auditoria, criptografia de dados privados, MFA/passkeys para perfis privilegiados e retenção controlada de documentos.

Transparência pública

Dados públicos do fundo são apresentados de forma agregada ou pseudonimizada, sem expor CPF, endereço ou motivo pessoal do auxílio.

Direitos do titular

O sistema possui base técnica para solicitações de acesso, correção e eliminação quando aplicável. Regras definitivas de retenção e bases legais devem ser validadas antes da operação real.

Documento de produto em desenvolvimento; requer revisão jurídica LGPD antes do uso em produção.
